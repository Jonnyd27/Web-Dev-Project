This is a project I completed during my time at Saint Martin's University. The project was to build a website utiilizing the MVC model, as well as the JavaScript, C#, HTML and CSS languages. I chose to do a website for a tattoo artist and her portfolio. This website including a few peices of her art, each with descriptions, as well as an interactable button
on the front page that changed the background of the website to which art peices button you pressed. And to finish the project I implemented ways to contact her for booking appointments as well as linked her Social Media.
This project was heavily supervised, as this was my first time coding any kind of project in any language. I had difficulties at first due to my lack of understanding of the languages syntax and built in functions. However, as I worked and progressed forward, I started to enjoy solving these issues and looking for new things to implement myself. The button
was an implementation of my own that my professor hadn't known how to do, since he focused more on back end development. In the end, and with quite of bit of struggling, I figured out how to make the button work. And that was the start to realizing I really enjoy coding.
